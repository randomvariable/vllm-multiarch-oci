## Hard ownership invariants

- The host, not GPU Operator, owns driver and toolkit.
- Exactly one NFD installation owns feature labels.
- Cilium owns the primary CNI; Multus adds secondary networks and must coexist non-exclusively.
- Network Operator advertises RDMA only; it does not install OFED or replace the host driver.
- LWS owns group lifecycle; EPP/Gateway own endpoint selection and routing.
- Tokens exist only in local environment/Secrets, never recipe data or browser state.
