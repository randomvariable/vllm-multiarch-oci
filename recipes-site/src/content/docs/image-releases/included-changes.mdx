Published images are built from pinned fork revisions of [`local-inference-lab/vLLM`](https://github.com/local-inference-lab/vllm) and [`local-inference-lab/B12X`](https://github.com/local-inference-lab/b12x), not from their upstream branches. A revision alone does not say which proposed changes it carries, so this page lists them.

A change reaches the build in one of two ways. It is either already merged into the pinned fork revision, or it is applied to the pinned source at build time from a patch in this repository. Both are recorded below, and the same list is written into the image's `org.opencontainers.image.description` label.

## vLLM

Pinned at [`904958d2e278`](https://github.com/randomvariable/vllm/commit/904958d2e278165b2722aab18cf4a65b696ab44f), branched from [`vllm-project/vllm`](https://github.com/vllm-project/vllm) `main`.

- **b12x GB10 integration ported from local-inference-lab karmic-kraken** — no upstream pull request
  - Merged into the pinned revision (1 commits).
  - One commit carries the fork's b12x path onto main: V2 runner, worker and engine-core preparation hooks; b12x paged attention, noncausal and GDN backends; Qwen4Exp b12x QSA, PLE, hyperconnection and MTP; PCIe/RoCE all-reduce; row-cache prefetch bridge and Prometheus relay; and upstream #65233, #65240 (MXFP4 CSF experts) and #67236 (NVFP4 draft lm_head on SM121) folded in; the follow-up entry below replaces #65240's host-side scale encoder. Dropped: recurrent boundary checkpoints, DCP-replicated hooks, adaptive-verification cost profiling, the b12x load format and the fork's ParallelLMHead quantization API.
- **DeepSeek V4.1 Engram tables served from checkpoint files** — no upstream pull request
  - Merged into the pinned revision (1 commits).
  - Extends main's Qwen4Exp engram-config disk_offload to DeepSeek V4.1: rows are read with preadv before graph replay, so the ~196 GiB of FP8 Engram rows take no device or pinned host memory on GB10.
- **b12x call sites moved to local-inference-lab FlashInfer APIs** — no upstream pull request
  - Merged into the pinned revision (1 commits).
  - MoE compressed scales use b12x online CSF compression (WeightPlanConstraints(scale_compression="csf")) instead of the CsfScalePlanes encoder local-inference-lab removed, and the scale swizzle is read from b12x._lib.intrinsics.reference.
- **Qwen4Exp b12x modules import their config from transformers** — no upstream pull request
  - Merged into the pinned revision (1 commits).
  - Fixes an import break in the b12x Qwen QSA, PLE and indexer modules after the fork's config shim was removed; MTP index sharing is read from the draft model config, where main's speculative-config plumbing sets it (default off).
- **Request-boundary recurrent checkpoints for Qwen3.8-Flash-Next** — no upstream pull request
  - Merged into the pinned revision (1 commits).
  - Ports local-inference-lab's boundary checkpoint cache, admission, endpoint reservations, capture/restore and KV connector hooks onto main, so the LMCache recurrent checkpoint connector resumes follow-up turns. Checkpoint keys cover only tokens below the endpoint under main's hash lookahead. Out of scope: GLM-5-Next, Kimi-K3/KDA, DFlash replay, DCP, LoRA and the fork's prefill-policy scheduler. Also fixes b12x profiling/warm-up hooks running without b12x and an env leak in a carried test.

## Keeping this list honest

`scripts/vllmb12x-included-changes.py --check` fails when this page, the README table, or the image description no longer matches the ledger, and when the recorded patch series no longer matches the patches Bazel applies.

`scripts/vllmb12x-included-changes.py --verify --clone-root <directory>` goes further and checks the ledger against the fork history: a pull request is integrated by replaying its commits, so the command asserts that every commit of every listed pull request is present in the pinned revision, and that the recorded commit count still matches.
