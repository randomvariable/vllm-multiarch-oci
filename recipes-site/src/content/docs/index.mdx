This project builds [`local-inference-lab/vLLM`](https://github.com/local-inference-lab/vllm) and its source dependencies for NVIDIA DGX Spark. It publishes an ARM64 OCI image and generates Kubernetes and Docker configuration for the two-node TP=2 deployments I run on two DGX Spark systems. It is not a builder or recipe catalog for upstream `vllm-project/vllm` releases.

## Open pull requests

- [vllm-multiarch-oci#25](https://github.com/randomvariable/vllm-multiarch-oci/pull/25) moves the builder onto the Qwen3.8 Flash Next pins and adds that recipe. It also keeps the hermetic flash-attn patch, accepts a pinned commit instead of a branch name as the source ref, and installs wheel console scripts so `ninja` exists at runtime.
- [local-inference-lab/vllm#777](https://github.com/local-inference-lab/vllm/pull/777) upstreams the fix the Qwen image carries: a target model's `hf_overrides` now reach the internally constructed MTP draft, so the draft keeps the same YaRN geometry and a 1,048,576-token prefill is accepted.
