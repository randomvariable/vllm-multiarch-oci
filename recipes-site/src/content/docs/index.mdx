This project builds [`local-inference-lab/vLLM`](https://github.com/local-inference-lab/vllm) and its source dependencies for NVIDIA DGX Spark. It publishes an ARM64 OCI image and generates Kubernetes and Docker configuration for the same DeepSeek V4 Flash Vision TP=2 setup used on two DGX Spark systems. It is not a builder or recipe catalog for upstream `vllm-project/vllm` releases.

  <div class="intro-copy">
    <p class="eyebrow">Kubernetes and Docker</p>
    <h2 id="site-purpose" class="large-copy">Generate Kubernetes and Docker configuration</h2>
    <p>
      Each page uses the DGX Spark image built from the pinned local-inference-lab/vLLM revision. It keeps the tested image separate from the newest publication, then renders Kubernetes and Docker artifacts from one authored definition. Site-specific network, storage, and resource values remain yours to supply.
