These recipes run the [`local-inference-lab/vLLM`](https://github.com/local-inference-lab/vllm) fork built for NVIDIA DGX Spark. A recipe fixes the engine behavior that was accepted. Host paths, network devices, allocatable resource names, selectors, and credentials remain deployment inputs. The validated image is always the default; a newer publication is offered separately and never inherits the recipe's acceptance status.
